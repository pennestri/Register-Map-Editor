Custom fields
Keys must be valid identifiers (letters, digits, underscore). The type is fixed once a field is created — it decides the input shown on each register and how the value is emitted in YAML: string is free text, integer accepts decimal or 0x notation, float accepts decimals, select renders a drop-down limited to the options you list (comma separated), and boolean renders a checkbox that emits true/false. Removing a field strips its values from every register; removing an option from a select field puts that field's default back on the registers that used it.
