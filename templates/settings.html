Default fields shown per register Uncheck to hide a field on every register card (and drop it from the exported YAML).
Custom fields
Keys must be valid identifiers (letters, digits, underscore). Defaults are applied to every register. Removing a field deletes its key from every register. Type controls the input shown on each register and how the value is emitted in YAML: string is free text, integer accepts decimal or 0x notation, float accepts decimals, select renders a drop-down limited to the options you list (comma separated), and boolean renders a checkbox that emits true/false.
